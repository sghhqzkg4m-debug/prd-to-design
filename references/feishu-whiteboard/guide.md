# 飞书原生白板

本指南把 `beautiful-feishu-whiteboard` 的 SVG 白板媒介规则并入 `prd-to-design`，用于需求文档中的流程、层级、关系、框架与角色旅程。原始规则由 Zara Zhang (@zarazhangrui) 以 MIT 许可证提供；复制的规则及许可见 [RULES.md](RULES.md) 和 [LICENSE](LICENSE)。主 Skill 无需再调用或安装原白板 Skill。

## 使用顺序

1. 根据 [飞书组件路由](../feishu-component-routing.md) 判断是否需要原生白板，并明确图要回答的设计问题。
2. 读取 [RULES.md](RULES.md) 的 SVG 媒介限制与渲染、写入、复核方法，读取 [palette.md](palette.md) 的默认深信服配色。已有文档风格或用户指定配色优先。
3. 以原生矩形、圆形、文本和连接线绘制；阶段、角色、状态的颜色编码保持一致，不能只靠颜色传达含义。
4. 本地渲染并检查溢出、重叠、箭头与可读性，再通过当前环境可用的飞书白板工具写入。`RULES.md` 中的 CLI 命令是工具可用时的实现示例；若当前环境提供等价飞书连接器，可用它完成同样的可编辑写入与实际预览验证。
5. 遵守主 Skill 的写入授权和原位更新规则。不能写入时保留本地 SVG 与预览，明确说明飞书同步尚未完成。

这份内置指南只固定白板的可编辑性、构图与默认视觉，不改变主 Skill 的需求分析、HTML 交付或飞书授权规则。
