# 深信服主题白板配色

颜色取自深信服云 BG 设计系统，具体色值已列于下表，无需安装其他 Skill。用于新建飞书白板的默认视觉；已有文档样式和用户明确指定的品牌优先。

| 用途 | 颜色 | 用法 |
|---|---|---|
| 品牌主色／主路径 | `#1770E6` 波塞冬蓝 | 关键节点、主连线、选中或当前阶段 |
| 深色标题／域边界 | `#242A33` 石墨烯黑 | 标题带、系统或业务域边界；深底使用白字 |
| 正文 | `#333333` | 节点与说明文字 |
| 次级文字 | `#666666` | 辅助说明；重要标签仍用正文色 |
| 背景 | `#F5F6FA` | 白板底色或大分区浅底 |
| 卡片 | `#FFFFFF` | 对象节点和信息卡 |
| 边框／分隔 | `#CCD1D9`／`#DCE0E6` | 容器边界与辅助连线 |
| 成功／完成 | `#50B371` 白俄罗斯绿 | 完成或正向结果，需配文字标签 |
| 警告／待确认 | `#FF9500` | 需关注节点，需配文字标签 |
| 失败／阻断 | `#E64545` | 失败或阻断路径，需配文字标签 |

以蓝色强调主任务，不把绿色当作第二品牌主色。背景与卡片保持大面积浅色；用深色标题和细边界建立层级。状态色只表达状态，不用来随意区分业务对象；对象类别优先通过分区、标题和线型识别。飞书 SVG 不支持透明度与模糊阴影，浅色层次应使用实色。确保文本与底色对比清晰，字号在实际飞书预览中可读。
