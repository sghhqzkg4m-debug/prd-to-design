# 用户旅程集成约定

旅程分析和 HTML 表达的详细规则已移至独立的 `user-journey` Skill。需要旅程时先读取其 `SKILL.md`，HTML 模式再读取该 Skill 内的 `references/html-current-journey.md`；按当前环境的 Skill 目录或已安装清单查找，不依赖某台机器的绝对路径。本文件保留原引用入口，避免已有模板与参考失效。

主 Skill 负责 JOB／Case、目标、范围和主文档编排；传入来源、角色、现状断点、目标与模板，接收按 Case 的完整旅程及证据。主 HTML 继续使用内置或用户指定模板，填充已有组件并保留六章骨架、样式和脚本；主飞书文档继续使用原生组件。旅程完整嵌入正文，动作和发现关联页面及验收，不以独立文档链接替代。默认不额外交付旅程文件。

集成检查：上下文与 Case 一致；阶段分组与动作列对齐；角色动作、依赖、交接和异常恢复完整；事实、推断和目标分开；HTML 筛选、全屏及窄屏可用。详细规则仅在 `user-journey` 维护。

如果未安装 `user-journey`，先尝试从同一安装包定位并读取。仍不可用时说明缺少旅程规则，保留已有旅程与模板组件，完成有证据支撑的任务／交接内容并标注待补核查；不得静默删去需求文档的旅程或声称已完成专业校验。
